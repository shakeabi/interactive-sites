Verification

Nothing measures whether the answers are right

Four unit-test files, 1,261 lines, every dependency mocked, no model invoked. One synthetic health query graded by a classifier for reachability. The firm's benchmark repo has entries for DPA, DESFlow, email and deep research — and none for this.

The 124/137 incident is the argument: that failure was invisible to everything currently in place.

Identity · DFlow#47079

Every user is the same user

No on-behalf-of flow. All data access runs as agt-i360chatprod, gated by one binary Turnstile grant with no row-level filtering. Access to Panorama is access to the union of everything the agent can read.

Ticketed, known, and the main constraint on how widely the tool can be handed out.

Capacity

Two brakes, both per-request

The sub-agent cap is enforced against a registry constructed per PyInfAgent — so global concurrency is 2 × concurrent_requests full CLI processes on one host, with no semaphore above it.

Meanwhile recursion_limit=500 × 8 s ≈ 4,000 s sits well past the 1,800 s nginx ceiling, so it never fires. Nginx is the real bound, and it expresses itself as a dropped connection.

Operations

Production runs from a personal directory

The DESFlow CLI path is /data/desim-mbo-tech-nb/shahdeve/desflow-claude-plugin, with a TODO to move back to /prod "once mounts are fixed" (claude_sdk.py:74,82).

Two termshell commits were shipped and reverted within three days in August; this workaround is what remained.

Readiness

A worker can be healthy and broken at once

Pool warm-up failure is caught and logged — but acquire() raises when start() never completed. The process comes up reporting healthy and fails every agent request.

Only the periodic health check would notice.

Documentation

The published architecture doc is wrong

docs/…/Architecture Overview.md still describes the pre-April design — RapidFuzz fuzzy validation, LangfuseInitializer, PersistentPythonInterpreter — with no mention of DocLab, Confluence, the agent SDK or the pool.

The Influence pipeline syncs it to Confluence on every merge, faithfully. Docs-as-code buys review and history. It does not buy accuracy.
