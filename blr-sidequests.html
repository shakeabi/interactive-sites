Turn on sync

The board is saving to this browser right now. To sign in with Google and sync across devices, connect a Firebase project. It takes about ten minutes and costs nothing at this scale.

  1. Create a project at console.firebase.google.com.
  2. Authentication, then sign-in method, then enable Google.
  3. Firestore Database, create in production mode, then paste the rules below.
  4. Project settings, add a web app, copy the config into FIREBASE_CONFIG at the top of this file's script.
  5. Authentication, settings, authorized domains: add wherever you host it. localhost is already allowed.
  6. Serve it over http. Run npx serve . or deploy with firebase deploy. Opening the file straight off disk will not work for sign-in.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /boards/{uid} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}
